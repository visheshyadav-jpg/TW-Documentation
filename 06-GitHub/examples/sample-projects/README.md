# Sample C++ Project

## 1. Introduction

This folder contains a simple C++ program created as an example project for demonstrating GitHub repository management.

## 2. Project Files

- `hello.cpp` – C++ source code.
- `hello.exe` – Compiled executable file.

## 3. Program Description

The program displays a greeting message on the console.

## 4. Compilation and Execution

Compile the program using:

```bash
g++ hello.cpp -o hello.exe
```

Run the executable:

```powershell
.\hello.exe
```

## 5. Output

```text
Hello, GitHub!
This is my sample C++ project.
```

## 6. Conclusion

This example demonstrates how source code and project documentation can be organized and maintained inside a GitHub repository.
