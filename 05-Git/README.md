# Git Basics

## 1. Introduction

Git is a distributed version control system used to track changes in files and manage source code. It allows developers to maintain project history, restore previous versions, and collaborate with others.

## 2. Objectives

- Understand basic Git commands.
- Initialize and configure a Git repository.
- Track and stage file changes.
- Commit changes and view commit history.
- Restore and revert changes.
- Understand how Git manages different versions of a project.

## 3. Practical Commands

The following Git commands are covered in this practical:

| Command | Purpose |
|---|---|
| `git init` | Initialize a repository |
| `git config` | Configure username and email |
| `git status` | Check repository status |
| `git add` | Stage changes |
| `git commit` | Save changes |
| `git diff` | View unstaged changes |
| `git restore` | Restore file changes |
| `git log` | View commit history |
| `git revert` | Undo changes through a new commit |
| `git rm` | Remove a tracked file |
| `git checkout` | Switch to an earlier commit or branch |

For detailed commands and descriptions, refer to the practical example file.
